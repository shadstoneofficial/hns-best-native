# hns:// Protocol Handler Extension

A standalone open-source native protocol for Handshake `.agent` domains. This repository contains the Manifest V3 Chrome extension that provides a native "Agent Dashboard" when users click `hns://` links.

## Features

- **Protocol Handler:** Intercepts `hns://` links and omnibox searches (keyword `hns`).
- **Agent Identity Card UI:** A React-based, dark cyberpunk/minimal UI to display Handshake agent metadata, `SKILL.md`, and connection info.
- **Gateway Fallback:** Includes a fallback to `hns.to` gateways for maximum accessibility.

## Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run dev server:**
   ```bash
   npm run dev
   ```

3. **Build the extension:**
   ```bash
   npm run build
   ```

4. **Load into Chrome:**
   - Go to `chrome://extensions/`
   - Enable **Developer mode**
   - Click **Load unpacked**
   - Select the `dist/` directory generated by `npm run build`
```
